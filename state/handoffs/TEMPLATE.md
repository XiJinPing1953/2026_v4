# 任务交接模板

按实际需要复制为日期与主题明确的文件；本模板不表示任何任务已完成。

- 目标行为与业务不变量：
- 用户已确认的决定、日期、替代规则：
- 基线提交/任务分支、前置修复、既存改动：
- 已做（文件或模块、行为改变）：
- 验证（实际命令、时间、结果、覆盖范围）：
- 未验证或未完成（具体原因与继续条件）：
- 发布（环境、源码提交、产物哈希、云函数/schema/调度清单、运行版本、核验时间；未知写未核实）：
- 下一步（明确动作、所需证据）：

完成后更新 STATE 快照；有效业务决定写回领域文件。未运行测试、未部署、待现场验收不可写成通过。原始客户数据及凭据留在受控本地位置，交接只写必要摘要。
