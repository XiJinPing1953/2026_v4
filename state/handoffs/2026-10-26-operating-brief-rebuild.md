2026-10-26。用户已批准按老板每日经营判断重建；本记录描述实现后的候选，不是生产发布记录。未改原账、数据库集合、液位换算模型或硬件行为。工作区另有灌装日期等未发布改动，不能直接把整个工作区视为本次发布范围。

## 实现与口径

- 阅读顺序为经营摘要、业务表现、期间货款、气量去向、期间收退款、当前客户资金、优先核对与依据、日报导出。摘要最多三条，由已验证数值确定性生成；客户贡献不表述为因果。
- “销售出货”改为“销售净气量”，含回瓶余气扣减；有效销售资格由现有 `operatingBriefFinance.active` 统一，首页、趋势、日报和导出成员清单一致。交易客户按原始销售客户去重；货款贡献按结算主体归集，两者明确分开。
- 7 个完整日小柱图保留负值、零线、真实零和待核缺口；可展开每日原值及原单。四行出罐横条共用比例尺、标 kg 与次数，部分渠道待核时保留已知渠道、停止显示总量及占比。与液位估算比较只使用同截止时点的出罐来源；日报业务日期与损耗实际时刻范围不强行勾稽。
- 昨天对前天并显示日期；今天只列进行中登记数。本月主累计包含今天，比较只用两月共同完整日 `N=min(日号−1,上月天数)`。月初无完整日不比较，基期非正数不生成百分比，来源待核不生成增速。历史均为按当前登记记录重算，并非历史冻结快照。
- 贡献列两期客户全集中绝对变化最大的三户及其他，含新增和本期未交易客户；合计回到总变化。无客户列表权限不返回贡献客户身份。
- 货款、已抵货款、销售/收款抹零和登记收退款分开。当前欠款/可用款不随日期切换，当前分配链核对与余额核对分列。合法历史嵌入款不被擅自改账；缺分配背书单独待核，矛盾按客户隔离，归属不明阻断汇总。
- 报表导出读取完整范围，以服务端 `sale_ids` 和逐单规范净气量为准，前后再读 `source_token`；无效旧单不误挡有效单，源单变化拒绝导出。金额使用后端计算字段，未取得完整账务依据时物理日报仍可读、导出禁用。

## 从原始材料到可检查结果

| 决策/指标 | 原始记录与日期 | 方法与限制 |
| --- | --- | --- |
| 销售净气量、瓶数、客户数 | `crm_sale_records` 出回瓶、整车称重、代理行；业务 `date` | 原单资格和重量规则共用；作废/隐藏排除，缺重量不得记零 |
| 期间货款及客户贡献 | 销售原单＋`crm_customer_flow_settlements` 表数、单价、结算 `biz_date` | 流量客户配送只记物理量，结算计货款；逐单精度后汇总；结算客户归集 |
| 登记收款/退款及去向 | `crm_customer_receipts`、`crm_customer_allocations`、`crm_cashier_intakes` | 收退款登记日期独立于业务日期；预收、抵款、押金、抹零与现金分开；跨期归属勾稽 |
| 当前资金及来源关系 | 上述资金记录＋`crm_customer_opening_debts`＋`crm_customers` | 完整读取、主户归属、有效分配链与源单已收快照核对；不推造历史日末余额 |
| 出罐/估算差额 | `crm_fillings`、`crm_gas_in`、`crm_operation_logs` 和现行液位换算 | 共用四渠道分类；不同业务时间明确区分；保持既有估算与缺源保护 |

旧页面、截图和旧汇总仅作对照，没有作为独立复算输入。`summaryV1` 保留原 `brief` 字段，新增 `analysis` 版本 `operating-analysis/2026-10-26.1`、按需分页的 `brief_sources`；每页校验来源内容 token 和源页面权限。日期、数值、分页数量与变更状态同时由前端校验。扩大的历史窗口失败/超限/读取变化时，只重读主期一次，历史仍待核，避免遮掉可核实的当期数字。

## 具体工具与证明范围

- Vue/uni-app 既有组件及样式变量；独立轻量柱条组件，无图表库和额外网络请求。没有使用会把缺失转成零的 `AppSparkline`。
- Node `node:test`：实际 handler、原始合成记录、前端真实 mapper/composable 与 Vue 渲染；覆盖零、缺单、负退气、作废、隐藏、未知归属、跨期退款、预收、抹零、多单分配、补录/源变更、UTC+8 跨日及月底。
- Python 标准库 `Decimal`：`scripts/verifyOperatingBriefEvidence.py` 不导入生产 JS 汇总函数。输入取证包中的原始行，生产输出仅作为比对目标；核对逐单、日期、分组、客户贡献、收退款与分配守恒、出纳气款/押金和四渠道。未知规则、缺源和哈希不符明确失败。
- Chrome 本地真实页面：320/390/768/1440px，检查图表、展开、日期切换、当前账款保持、分页 50→51、来源变化拒绝、局部出罐失败、真实零、键盘 Enter 和原单路由；触控入口至少 44px。演示明确标为合成数据，详情跳转只证明路由，未冒称现网原单内容验收。
- Impeccable 对本次组件做定向视觉/技术检查；无人工体验评分、无新增自动钩子。H5 构建和领域规则副本检查另记日志。

私有证据在 `outputs/trust-audit/2026-10-26-operating-brief-rebuild/` 和 `outputs/trust-audit/2026-10-26-operating-brief-independent/`（均被 Git 忽略）。取证包包括查询范围、逐笔成员、行数、读取起止、规则版本和内容 SHA-256。封包只防止材料被无声替换，不证明材料本身真实或读取具有跨表原子性。未把客户原始明细加入公开产物。
