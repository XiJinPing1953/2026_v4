适用：储罐、充装许可、秤和 RFID。本文件维护产品边界，协议细节仍在对应实现文档。当前安装/云端版本均需按 [STATE](../../STATE.md) 的证据核实。

## G-01：CRM 根入口独立（2026-08-26，2026-09-05确认）

来源：[归档 STATE](../history/STATE-2026-08-26.md) `2026-08-26 CRM 根入口与发布前置检查修复`；替代误把储罐 renderer 写入 CRM 根 index.html 的混用。

CRM 根 `index.html` 保留 uni-app 入口；储罐使用 `apps/tank-gateway/renderer/index.html`。H5、PDA、储罐、充装许可分别记录源码、产物哈希、目标环境与验收状态；不能用同一个网页时间戳证明所有产品已升级。

## G-02：各网关职责不混合（2026-04～08，2026-09-05确认）

| 网关 | 当前职责和协议来源 | 验收边界 |
|---|---|---|
| 秤 | [C606+ 与云端最新重量](../../scripts/scale-gateway/README.md) | 实际串口、稳定值、离线与 PDA 回填 |
| RFID | [TCP 收帧、会话、云入库](../../scripts/rfid-gateway/README.md) | 真实读卡和独立上传状态；会话幂等 |
| 储罐 | [应用](../../apps/tank-gateway) | Windows 安装、监控屏、四级声音报警及现场断连 |
| 充装许可 | [V1 交付与投运](../../docs/filling_permit_gateway_v1.md) | HMI/PLC 通信和许可清零逐项现场验收 |

充装许可流向为 HMI → Windows 网关 → 云校验，HMI 通过现有 PLC 驱动写最终许可；不能绕过急停/设备联锁。储罐修正值用于本地报警比较，不擅自改 PLC 原始值或云上报。上述职责来源于已批准的领域实现，更新现场控制行为必须有对应业务决定和验收证据。
