# 展示、导出与上传

适用：首页、表格导出、自动补全和上传。来源：原项目技能 2026-04 事故经验，2026-09-05 合并为按需规则；不替代各业务的权威金额定义。

- 首页默认轻量汇总；不为月报导出扩大首页请求窗口。显示可截取可见行，导出必须覆盖用户选择的完整业务范围，并传播计算完整性；避免“只显示标题”或数值列变文本。
- 自动补全复用现有稳定弹层：输入框定位、宽度对齐、边界不裁切、点击先选择再收起。按实际平台查验，不把固定 z-index 数字当跨页面保证。
- 上传超时、回执异常或调用中止意味着状态待确认。相同文件尝试使用稳定 cloudPath/幂等键，先核实对象是否已存在再决定重试；明确参数/权限/大小错误直接显示原因。上传存在不等于业务记录已保存，两者都要有结果。

代码按任务定位，权威金额见 [账务](accounting.md)，数据库写入和授权见 [工程约束](../../docs/RULES.md)。
