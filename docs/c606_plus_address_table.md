# C606+ 地址表

整理日期：2026-06-07

本表按当前 `scripts/scale-gateway` 已接入的 C606+ 网关口径整理。地址以 Modbus RTU 报文里的 0 基 PDU 地址为准；如果调试软件使用 1 基地址或 `3xxxx/4xxxx` 显示法，请参考“常见 1 基显示地址”列。

## 通讯参数

| 项目 | 当前口径 |
| --- | --- |
| 仪表 | 耀华 C606+ |
| 通讯方式 | RS485 两线 Modbus RTU，使用 C606+ 串口 3 两线 Modbus 模式 |
| 默认串口 | `9600 / 8 / none / 2 stop bits` |
| 特殊说明 | 若现场仪表改为奇/偶校验，网关也要同步改为 `odd/even / 1 stop bit` |
| 默认站地址 | `1`，与 `SCALE_SLAVE_ID` 保持一致 |
| 字节序 | 32 位数据高 word 在前 |

## 单位码

| unitCode | 单位 | 换算到 kg |
| ---: | --- | --- |
| `0` | mg | `value / 1000000` |
| `1` | g | `value / 1000` |
| `2` | kg | `value` |
| `3` | t | `value * 1000` |

## 读取顺序

1. 读取配置块：`FC04 0x001C, 11`，缓存分度值、小数位、单位码。
2. 读取动态灯：`FC02 0x0002, 1`。
3. 优先读取毛重浮点：`FC04 0x0008, 2`。
4. 如果浮点毛重读取或解析失败，回退读取毛重整数：`FC04 0x0002, 2`。
5. 统一输出 `weight_kg`，并写入云端最新秤值。

## 写目标顺序

1. 网关从云函数领取待写任务。
2. 将目标净充重量 `target_net_weight` 编码为 `Float32` 高 word 在前。
3. 使用 `FC16 0x00CA, 2` 写入定量 1。
4. 使用 `FC03 0x00CA, 2` 读回校验。
5. 把写入结果回写云端任务状态。

## 当前未确认项

| 项目 | 当前处理 |

| 超载位 | 尚无明确 C606+ 寄存器地址，当前 `overload_supported=false`，`overload=null` |
