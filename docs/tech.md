**客户对账说明书（示例客户：华丰皮革厂-王建新涂浆）**  
口径基准：按你当前系统实现（2026-04-12）整理。

**1. 这页到底管什么**
- 这页是“客户级总账 + 操作台 + 流水明细”。
- 能做的核心动作就是你图里的 7 个操作：`登记收款/分配`、`冲抵分配`、`预付录入`、`冲抵池录入`、`历史欠款登记`、`其他费用`、`收款单`。
- 所有动作最终都会回写到客户总览卡片、销售明细、账务流水、导出对账单。

**2. 顶部四张卡片口径（最重要）**
- `应收余额(未扣冲抵)`：所有应收目标未收合计。  
  目标包含：销售单、流量结算、历史欠款、其他费用。
- `可冲抵余额`：所有已入账收款单里的“未分配余额”合计。  
  包含两类：普通预付 + 冲抵池来源。
- `净欠款(扣冲抵后)`：`应收余额 - 可冲抵余额`。
- `最近回款`：当前筛选范围内，`amount > 0` 的收款单 `biz_date` 最大值。  
  纯抹零单（收款金额=0）不会更新“最近回款”。

**3. 时间范围规则（你最近关心的点）**
- 页面默认是`本年累计`（例如 2026-01-01 到当天）。
- 顶部“开始/结束 + 查询日期”会同时影响：
  - 顶部卡片
  - 客户总览里的累计营收/累计实收/其中预付款/其中冲抵池
  - 账务流水与导出
- 快捷键有`本年累计`和`本月累计`。

**4. 账务操作区（7个Tab逐个说明）**

1. `登记收款/分配`
- 字段：收款金额、抹零金额、业务日期、收款方式、分配模式、备注。
- 分配模式：
  - 时间段分配：按日期区间自动冲欠（先老后新）。
  - 勾选分配：只冲你勾选的目标单据。
- 规则：
  - 收款金额和抹零金额不能同时为 0。
  - 抹零不能小于 0，且必须全部落到应收目标（不能悬空）。
- 示例：  
  2026-03-07 登记 `收款522`、`抹零0`，勾选“2026-03-07那笔欠款585”，提交后这笔欠款剩余 63。  
  再用冲抵分配把 63 冲上去即可结清。

2. `冲抵分配`
- 用途：把冲抵池来源（比如销售多收、赔付款）手工冲到指定欠款。
- 现在支持：来源多选 + 勾选目标多选 + 时间段分配。
- 提交逻辑：按已选来源逐笔扣减，不回滚历史分配。
- 示例：  
  来源A可用 396（2026-02-26），来源B可用 200（2026-03-01）。  
  本次冲抵金额填 500，勾选目标只选“2026-03-07欠款”。  
  系统会先从A扣，再从B扣，直到 500 分配完成或来源耗尽。

3. `预付录入`
- 用途：客户先付款。
- 策略：
  - 仅入预付：不冲欠，余额留在预付。
  - 立即按区间冲欠：先冲所选区间欠款，剩余进预付。
- 示例：  
  2026-03-10 录入预付 1000，选“立即按区间冲欠（3月）”，若区间内可冲 620，则剩余 380 进入预付。

4. `冲抵池录入`
- 用途：手工录入“给客户赔付但不退现金”的金额进入冲抵池。
- 特点：只入池，不自动冲销，后续必须去“冲抵分配”手工分。
- 示例：  
  2026-03-12 录入冲抵金额 300（备注“质量赔偿”），随后到“冲抵分配”冲给指定欠款日期。

5. `历史欠款登记`
- 用途：录系统启用前欠款（期初应收）。
- 当前表单只保留：金额、业务日期、备注（不再新增抹零输入）。
- 可编辑/删除；但若已被收款分配过，不能直接删。
- 示例：  
  2026-01-01 登记 12000，作为期初欠款进入账务。

6. `其他费用`
- 用途：非销售类应收（如运费、罚款、杂项）。
- 行为上和“历史欠款”类似，也会参与收款/冲抵分配。
- 示例：  
  2026-03-18 登记其他费用 260，后续可被收款或冲抵池冲销。

7. `收款单`
- 显示近20条收款单（默认折叠）。
- 可编辑/删除；删除会回滚该收款单产生的分配。
- 每条会显示：收款、抹零、已分配、预付+。

**5. 销售明细区怎么读（你经常核对的地方）**
- `应收`：销售应收原值。
- `抹零`：该销售单抹零（若有）。
- `实收`：手工实收；若有冲抵，会分开展示“冲抵金额”和“入账金额”。
- `未收`：按计费应收减去实收与抹零后的剩余。
- 若出现多收，会提示：
  - `可入冲抵池，需手工分配`（已开冲抵）
  - `未入冲抵池`（未开冲抵）

**6. 账务流水区怎么读**
- `sale`：销售应收行
- `flow_settlement`：流量结算应收行
- `opening_debt`：历史欠款行
- `other_fee`：其他费用行
- `receipt`：收款行（含抹零、预付+）
- `allocation`：分配行（收款分配/抹零分配/冲抵分配）

**7. 导出对账单（当前是双Sheet）**
- Sheet1：`客户对账单`（期初、每日应收/收款/抹零/余额）
- Sheet2：`销售明细`（销售日期、应收、实收、抹零、未收、状态）
- 期初余额会纳入你已登记的历史欠款（例如 2026-01-01 期初欠款）。

**8. 用“华丰皮革厂-王建新涂浆”做一套完整例子**
- 2026-01-01：历史欠款登记 12,000。
- 2026-02-03：销售单应收603，实收666，多收63入冲抵池。
- 2026-02-06：销售单应收585，实收522，未收63。
- 2026-02-09：冲抵分配，来源选“2月3日多收63”，目标勾选“2月6日欠款”，冲抵63后该单结清。
- 2026-03-18：其他费用登记260。
- 2026-03-20：登记收款100、抹零5，分配给“3月费用”，则该费用未收从260变155，且“最近回款”按这笔收款业务日期更新。

**9. 财务对齐建议（实操顺序）**
1. 先选时间范围（建议先`本年累计`，再切`本月累计`复核）。  
2. 看四张卡片是否与会计账期一致。  
3. 用`收款单`核对每笔回款日期与方式。  
4. 用`冲抵分配`核对“冲抵到哪一天”。  
5. 用`账务流水`追每笔差异。  
6. 最后导出双Sheet给会计复核签字。
