# 工业气瓶全流程追溯与经营管理系统演示视频

## 视频定位

本视频用于向客户、老板和项目验收人员说明：这套系统不是普通 CRM，也不是独立扫码台账，而是一个基于真实经营业务的工业气瓶追溯系统。

核心表达：

- 真实业务驱动追溯：销售、灌装、回瓶、配送、盘点、对账都沉淀为气瓶追溯事件。
- 追溯反哺经营管理：追溯结果帮助企业管钢瓶、查异常、控风险、做客户对账。
- 现场数据直接进入系统：PDA、RFID、称重、业务录单共同形成可查询、可核对的数据链。

建议成片时长：5 分 20 秒左右。

建议主标题：工业气瓶全流程追溯与经营管理系统

建议副标题：真实业务驱动追溯，追溯反哺经营管理

## 拍摄前准备

- 准备一个完整演示瓶号，能展示回瓶、灌装、出瓶、销售、客户、单瓶时间线。
- 准备一个异常案例，优先使用缺回瓶、缺灌装或连续出瓶，用于展示追溯风控价值。
- 准备一条 RFID 门口盘点会话，能看到车辆、瓶子明细、读取次数、绑定状态，最好包含未绑定或未知标签。
- 准备一个客户对账案例，能看到应收余额、预付/冲抵、最近回款和对账导出入口。
- 录屏前脱敏客户电话、真实金额、账号密码、云函数 URL、网关密码、ECS 地址等敏感信息。

## 字幕建议

- 真实业务驱动追溯
- 追溯反哺经营管理
- 出瓶、回瓶、灌装形成气瓶生命周期
- RFID 门口盘点辅助现场校验
- PDA 一线作业直接沉淀追溯数据
- 客户对账、收款、报表形成经营闭环

## 表述边界

- 不要把系统称为普通 CRM；客户和对账只是经营闭环的一部分。
- 不要说 RFID 自动生成销售单；当前 RFID 只做门口盘点入库、查看、标签绑定和异常辅助识别。
- 不要说 RFID 自动修改瓶子流转状态；实际流转仍以销售、回瓶、灌装等业务单据为准。
- 不要把追溯讲成单独扫码功能；追溯链应来自真实业务流程。

## 验收清单

- 视频中至少出现一次完整追溯链路：瓶号 -> 时间线 -> 出瓶/回瓶/灌装事件 -> 异常或闭环状态。
- 视频中至少出现一次经营闭环：客户 -> 销售 -> 收款/对账 -> 报表。
- 视频中至少出现一次现场数据采集：PDA 扫码、PDA 称重或 RFID 门口盘点。
- 视频旁白没有夸大 RFID 当前能力。
- 视频画面未暴露敏感客户信息、账号密码、云函数 URL、网关密钥。
