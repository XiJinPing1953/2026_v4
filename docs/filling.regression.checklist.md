# 灌装模块回归清单（收尾版）

适用版本：`filling-v1.0-closeout`（2026-03-17）  
目标：在大规模全量导入前，快速确认灌装主链路稳定。

## 0. 前置条件

- 已上传最新云函数：`crm-filling`。
- 当前空间：`env-00jxuffegf2n`。
- 使用管理员账号登录。
- 钢瓶档案中有可用测试瓶（`is_active=true`）。

## 1. 查询与联想

1. 进入“灌装记录”页面。
2. 在查询条件输入瓶号关键字，出现联想建议，点选后回填。
3. 在查询条件输入操作人关键字，出现配送员联想建议，点选后回填。
4. 点击“查询”。

验收：
- 联想下拉无错位/无遮挡。
- 查询结果与筛选一致。

## 2. 单条灌装

1. 点击“单条灌装”。
2. 选择日期、瓶号、净重、作业类型、操作人（默认应为“陈铁栓”）。
3. 点击“保存”。

验收：
- 保存成功后列表立即出现新记录。
- `truck_out_no_sale` 类型允许空瓶号。
- `normal_fill / truck_out_agent_sale` 类型若空瓶号应被阻止。

## 3. 批量新增（预览明细）

1. 打开“批量新增灌装”。
2. 输入多行：`瓶号 空格 净重`（或 `瓶号,净重`）。
3. 点击“预览”。

验收：
- 预览分三段：`待新增`、`已存在冲突`、`无效行`。
- 明细包含：行号、瓶号、净重/错误原因。

## 4. 批量改日期

1. 在列表筛选一批记录。
2. 打开“批量改日期”。
3. 先“预览”，再“执行”。

验收：
- 预览命中数与当前筛选一致。
- 执行后列表日期更新正确。

## 5. 删除动态刷新（本次修复重点）

1. 在当前列表删除任意一条灌装记录。
2. 不手动刷新页面，直接观察列表。

验收：
- 列表立即移除该记录（不等待缓存 10 秒过期）。
- 再点“刷新/查询”不会出现已删除记录。

## 6. 导出与排序

1. 在任意筛选下执行导出。
2. 打开导出文件检查顺序。

验收：
- 导出条数与筛选总数一致。
- 瓶号自然升序正确（数字号连续、前缀规则一致）。

## 7. 构建与语法

执行：

```bash
node --check uniCloud-alipay/cloudfunctions/crm-filling/index.js
npm run build:h5
npm run build:mp-alipay
```

验收：三条命令均通过。
