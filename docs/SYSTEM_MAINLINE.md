1. **首批工程交付已收齐并验收。** 主任务核对基线、差异和失败反例；补齐公共副本及统一检查，并修复两处整车扫描完成状态缺陷。当前118项本地验证通过，推进发布和两个入口补口，不追加无关结构改造。
2. **先交付通用账务规则。** 以已发布客户修复为保护条件；销售、结算和导出对同一来源一致，期初不会变成新收款，不完整读取不会给出可信总数。核清最小发布范围后，由主任务统一发布并读取真实业务结果。首页/催收只对本次实际覆盖的指标宣称完成。
3. **再交付灌装闭环。** 本地反例通过后，在隔离可恢复范围验证真实云事务、触发器、53瓶中断续跑和幂等。前后端及PDA按兼容条件成套切换，生产真实瓶不充当未经安排的测试对象。测试环境或现场条件缺失时，记录具体条件并继续其他独立工作。
4. **发布后独立核对。** 运行版本对应源码及产物；两家客户的已确认行为不退回；关键源数据前后可比较。测试通过不能替代生产验收。
5. **验收后决定扩展。** 再安排销售多对象写入、历史改单恢复、催收流量债权和汇总提速；本阶段不做全仓重写、技术栈迁移或硬件路线更换。
