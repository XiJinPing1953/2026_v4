# 灌装全链路冒烟手册（收尾版）

目标：验证“灌装台账、库存 movement、异常/损耗口径”一致。  
原则：每一步都可回滚，先小样本再批量。

## 0. 准备

- 空间：`env-00jxuffegf2n`
- 账号：管理员
- 选 2 个在档且启用钢瓶：
  - `B1`：用于 `normal_fill`
  - `B2`：用于 `truck_out_agent_sale`
- 记录当前时间作为 `T0`

建议新建一个临时备注：`smoke-20260317`，便于后续快速筛选和回滚。

## 1. 基线快照（执行前）

1. 打开“灌装记录”页，按备注 `smoke-20260317` 查询，确认当前为 0 条或记录基线条数。
2. 打开库存异常/损耗页面，记录当前总数（截图即可）。

## 2. 用例 A：normal_fill（应写 movement）

1. 在“单条灌装”新增一条：
   - 作业类型：`normal_fill`
   - 瓶号：`B1`
   - 备注：`smoke-20260317-A`
2. 保存后返回列表，确认新增成功。

验收：
- 台账有记录。
- 该瓶相关库存链路可见对应变化（按你当前页面口径核对）。

## 3. 用例 B：truck_out_agent_sale（应写 movement）

1. 新增一条：
   - 作业类型：`truck_out_agent_sale`
   - 瓶号：`B2`
   - 备注：`smoke-20260317-B`
2. 保存并检查列表。

验收：
- 台账有记录。
- 库存链路参与统计（与 A 同口径）。

## 4. 用例 C：truck_out_no_sale（不写 movement）

1. 新增一条：
   - 作业类型：`truck_out_no_sale`
   - 瓶号：可空
   - 备注：`smoke-20260317-C`
2. 保存并检查列表。

验收：
- 台账有记录。
- 库存异常/损耗口径不应因该条发生额外变化。

## 5. 删除刷新校验（动态刷新）

1. 在当前列表删除 `smoke-20260317-C`（或任意 smoke 记录）。
2. 观察列表是否立即移除。

验收：
- 删除后立即刷新，不出现“删了但还在列表里”的延迟。

## 6. 回滚（可撤销）

1. 在灌装列表按备注 `smoke-20260317` 查询。
2. 逐条删除本次 smoke 记录。
3. 刷新页面，确认 smoke 记录为 0。

说明：
- 本手册只新增临时测试记录，回滚方式就是删除这些记录。
- 每条删除都会触发异常链路同步更新，回滚后口径应恢复。

## 7. 通过标准

- A/B 两类记录：台账成功且参与库存链路。
- C 类记录：台账成功但不进入库存链路。
- 删除后列表即时刷新。
- 回滚后 smoke 记录清零。
