# DSX 开机取零与运行零点跟踪（移植件）

本目录只含零点计算。适配对象是 1000 kg 秤台、0.5 kg 主显示。没有 1300 的寄存器表完整实现、ADC 驱动、BLE 发帧、启动代码或可刷镜像。

**集成位置。** 在经过标定的有符号毛重（整数 mg）与工作重量输出之间调用；每次新的、有效的传感器转换只调用一次，时间来自单调毫秒时钟。尚未 ready 时上报“初始化”，禁止把默认 0 当成重量。ready 后输出 gross_mg - offset_mg。RS485 与 BLE 必须读同一个工作值；维护接口另保留原始毛重、AD 和时间戳。不要用“稳重锁定寄存器”替代实时重量。有传感器故障、超载等异常时优先报告异常，不作零点采集。掉线后需使无有效样本期间的工作重量失效。

**只保留一个零点跟踪来源。** 集成前确认固件既有的零点/判稳算法、用户临时去皮及传感器预热次序。用此模块替代对应补偿或保留原生更优实现；不可不经验证串接两套跟踪。开机、标定完成和更换传感器时 reset，标定/去皮期间由调用方旁路，工作零点不进 Flash、不改标定系数。兼容已有 0x22 毫克帧以及现场 Modbus 地图是集成验收条件。

**试验参数。** 连续有效样本至少 5 次且至少 2 s，峰峰差最多 0.05 kg，超过 500 ms 视为窗口中断。只在稳定样本全部严格落在 ±0.25 kg 内才取启动零点。明显负载即使稳定也不取零。负载变化持续时最长 5 s 放行实时重量，校准/复秤的独立判稳继续起作用。跟踪限速最多 0.010 kg/s，原始值和两个参考值都有边界；回到中心 ±0.025 kg 并稳定时撤销修正。超过范围后保持已有修正量，真实减重继续传出。亚分度的小物体与同量级的零漂单靠重量不可区分。

**证据与限制。** 运行 `python3 scripts/replayDsxZero.py outputs/trust-audit/2026-11-04-dsx-com3` 可用原始 03 帧逐样本比较 C 与 JS。主板适配仍需 1300 对应源码或厂家提供的兼容固件、参数和回退方式；不要用现有资料包中的其他版本覆盖 1300。20 kg 试验、短时重启、软件慢速减载回放不能替代实物慢减载、隔夜、搬场和带载上电验证。
